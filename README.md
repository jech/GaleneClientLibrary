# Galene client library for Java

This repository contains a somewhat incomplete client library for the
[Galene][1] videoconferencing server.  It might or might not be maintained
in the future.

It has been extracted from the (now abandoned) [native client][2] for
Galene, so it is sufficient for writing a simple native client.  Since the
Android ecosystem is not friendly to free and open source software, I do
not intend to maintain it any further.

[1]: https://galene.org
[2]: https://galene.org/android/
